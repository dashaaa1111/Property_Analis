# 🏙️ Аналитика рынка недвижимости: СПб и ЛенОбласть



Проект для агентства недвижимости из Петрозаводска, планирующего выход на рынок Санкт-Петербурга и Ленинградской области. Проанализированы архивные объявления Яндекс.Недвижимости за 2015–2018 гг.

## 🎯 Задачи

1. **Сегментация рынка** — определить привлекательные сегменты по времени активности объявлений.
2. **Сезонность** — выявить периоды повышенной активности продавцов и покупателей.
3. **Дашборд** — доработать интерактивный дашборд в DataLens.

## 🗂️ Данные

Схема `real_estate`: таблицы `flats`, `advertisement`, `city`, `type`.

## 🔬 SQL-анализ

- Очистка выбросов по 1-му и 99-му перцентилям.
- Категории экспозиции: до месяца, 1–3 мес., 3–6 мес., более полугода.
- Сравнение СПб и ЛенОбласти по цене, площади, комнатам, этажу.
- Анализ месяцев публикации и снятия объявлений.

**Выводы:**
- Наиболее ликвидны квартиры со сроком продажи до 3 месяцев.
- Пики публикаций — весна и осень.
- Летом активность снижается.

## 📊 Дашборд DataLens

Две вкладки:

- **Аналитика рынка** — KPI, динамика цен, топ-5 городов, средние сроки продажи.
- **Детализация** — стоимость м² по городам, планировкам, апартаментам, влияние парков и водоёмов, сезонность.

## 🛠️ Стек

`PostgreSQL` · `DBeaver` · `DataLens` · `SQL (CTE, оконные функции, PERCENTILE_DISC, FULL OUTER JOIN)`

## 🚀 Результат

Заказчик получил обоснованный выбор сегмента, календарь сезонности и готовый дашборд для мониторинга рынка.
